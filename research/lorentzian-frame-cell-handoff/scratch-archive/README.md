# scratch-archive

Snapshot (2026-10-17) of research scratch scripts, logs and small data files that were not yet mirrored under `code/`.
Paths are relative to the original scratchpad, so `scratch-archive/lor6/screen.py` is `scratchpad/lor6/screen.py` as
cited in HANDOFF.md and NOTES-full-log.md.

- Included: `*.py`, `*.c`, `*.sh`, `*.log`, `*.md`, `*.txt` up to 300 KB, plus a few small `declp/*.pkl` data files.
- Not included: large pickles/npz (regenerable by the scripts), word archives, VM bundles, and downloaded
  discussion/PR material (untrusted; read it with `python -I` if re-fetched).
- Scratch quality: not reviewed, may contain stale or superseded experiments.  HANDOFF.md is the index of
  conclusions; this directory is only the provenance of the numbers quoted there.
